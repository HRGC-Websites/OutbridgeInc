# Outbridge Inc

Marketing site for **Outbridge Inc** — outsourced teams for support, sales and operations.

A fully static HTML/CSS/JS site. No build step.

## Pages

- `index.html` — Home
- `services.html` — Service lines
- `about.html` — Company
- `careers.html` — Open roles
- `compliance.html` — Compliance & policies
- `newsletter.html` — Posts & subscribe
- `contact.html` — Booking form & FAQ

## Stack

- Plain HTML
- CSS in `assets/site.css` (Bricolage Grotesque + Hanken Grotesk via Google Fonts)
- JS in `assets/site.js` (reveal-on-scroll, mobile menu, FAQ accordion, form handlers, count-up stats)
- Inline SVG illustrations generated by `assets/illustrations.js`

## Local preview

Any static server will do, e.g.:

```bash
npx serve .
```

Then open `http://localhost:3000`.

## Deployment

Deployed on **Vercel** as a static site (no framework). Production builds on every push to `main`.

The included `vercel.json` enables clean URLs, long-cache headers for `/assets` and `/uploads`, and basic security headers.
